# 모바일웹 와이어프레임 (가제)

`기획서_v1`의 핵심 플로우(익명질문 → 또래공감 → AI검수 → 전문가답변)를 기반으로 만든 4개 화면 와이어프레임.

- `Main.dc.html` — ① 온보딩 · 연령 선택 (10대/20대)
- `Home.dc.html` — ② 홈 · 질문 피드 (커뮤니티 탭, 질문 리스트, 질문하기 버튼)
- `Ask.dc.html` — ③ 익명 질문 작성 (카테고리, 본문 입력)
- `Detail.dc.html` — ④ 질문 상세 · 답변 타임라인 (또래 답변 → AI 검수 → 전문가 답변, 신고)

`canvas.json`은 각 화면(artboard)의 캔버스 배치 정보를 담은 인덱스 파일이며, 원본은 Claude Artifact(Design 캔버스)로 작성되었다.
