## 핵심 기능 (기획서 그대로)
1. Q&A 커뮤니티 (기존 플로우 유지) — 익명 질문 → 또래 공감 → AI 1차 검수 → 전문가 답변 보강
2. 성지식 매거진 (신규) — "언니가 알려주는 포인트" 코너, 전문가 감수 아티클
3. 고민상담 (신규) — '언니 AI' 24시간 상담 + 전문가 1:1 예약 상담, 완전 익명
4. 성지식 라이브러리 (신규) — 검색·카테고리별 용어사전
