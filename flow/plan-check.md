# 기획 점검 (플로우 기준)

기준: 기획서 v3 (`research/기획서_v1.md`, 2026-11-20), 플로우 1 (`flow/flow.md`)

## 1. 기능에서 플로우로

| 핵심 기능 | 어느 플로우, 몇 단계에 나오나 | 어느 화면에서 | 판정 |
|---|---|---|---|
| 커뮤니티 · 익명 질문 (사진 첨부) | 플로우 1, 2~4단계 | 3.0, 3.1 | 들어감 |
| 커뮤니티 · 연령대별 탭 분리 | 플로우 1, 3단계 | 3.0 | 들어감 |
| 커뮤니티 · AI 검수 (부적절한 글·사진 차단) | 플로우 1, 4단계 갈림길 | 3.1 | 들어감 |
| 커뮤니티 · 또래 답변 | 플로우 1, 6단계 | 3.2 | 들어감 |
| 커뮤니티 · 전문성 필요 글을 AI Q&A로 이동 | 플로우 1, 5단계 갈림길 | 전문가 질문 작성 (새 화면) | 들어감 (화면은 아직 없음) |
| AI Q&A · 전문가 질의응답 | 플로우 1, 5단계 갈림길에서만 | 4.0 | 약함: AI가 글을 잡아낼 때만 거침. 사용자가 직접 전문가에게 가는 길은 플로우에 없음 |
| AI Q&A · 언니 AI 24시간 상담 | 없음 | 4.0 | 빠짐 |
| 성지식 매거진 (아티클별 연령 제한 포함) | 1단계에서 홈을 지나가기만 함 | 2.0, 2.1 | 약함: 화면은 있지만 플로우에서 거치지 않음 |
| 성지식 사전 | 없음 | 5.0 | 빠짐 |
| 회원가입 · 본인인증 | 1단계에서 "이미 끝난 상태"로 가정 | 1.0 | 빠짐 |
| 튜토리얼 (구성·사용법·주의사항) | 없음 | 2.0 안내 카드만 있음 | 빠짐 |
| 신고 (사진 첨부, 승인 시 이용 정지) | 없음 | 3.2 신고 버튼만 있음 | 약함 |
| 푸시 알림 · 첫 등록 때 동의 | 플로우 1, 4·5·6단계 | 푸시 알림 동의 (새 화면) | 들어감 (화면은 아직 없음) |

## 2. 플로우에서 기획서로

| 플로우·화면에 있는 것 | 기획서 | 메모 |
|---|---|---|
| 답변 채택, 도움됐어요, 댓글로 더 묻기 (6단계, 3.2) | 없음 | 기획서는 "또래가 답변"까지만 적혀 있음 |
| AI 검수가 또래 답변보다 먼저 (4단계: 올리는 순간 차단) | 기획서 ① 표는 1 질문 → 2 또래 답변 → 3 AI 검수 순서 | 순서가 서로 다름. 기획서 본문("업로드를 막는다")은 플로우와 같은 뜻 |

## 3. 퍼소나로 다시 보기 (김서윤, 17세)

| 김서윤의 목표·어려움 (기획서 2장) | 플로우 1에서 해결되는 지점 | 남은 불편 |
|---|---|---|
| ① 들키지 않고 질문 / 친구·가족에게 민망함 | 3.1 익명 작성, 3.0 연령대 탭 분리 | 없음. 가입 때 본인인증을 하지만 활동은 익명 |
| ② 정보의 전문가 검증 / 인터넷 정보의 불일치 | 병원·건강 글은 AI가 잡아내 전문가에게 보냄 (5단계) | 남음. AI가 잡아내지 않은 질문은 또래 답변만 받고 끝남. 3.2에서 본인이 전문가에게 이어 물을 길이 없음 |
| ③ 또래 경험 참고 | 3.2 또래 답변, 채택·댓글 (6단계) | 없음 |
| ④ 쉬운 설명 | 플로우에 매거진·사전이 나오지 않음 | 남음. 쉬운 설명을 주는 사전·매거진으로 가는 길이 플로우 1에 없음 |

근거 인터뷰: "혼자 검색하다가 더 헷갈릴 때가 많아요. 익명으로 물어보고 정확한 답을 알고 싶어요." (페르소나 C · 김서윤), "친구들한테 물어보기에는 너무 민망해요. 익명으로 물어볼 수 있으면 좋겠어요." (응답자 P2)
