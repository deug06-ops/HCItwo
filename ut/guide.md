# 사람 사용성 평가(UT) 진행 가이드

`ut/plan.md`(평가 계획)를 실제로 진행할 수 있게 정리한 문서예요. 참가자 3명(P1, P2, P3)에게 같은 방법으로 진행해요.

- 한 사람당 걸리는 시간: 약 30분 (인사·동의 5분, 사전 질문 3분, 과제 3개 15분, 사후 질문 5분)
- 역할: **진행자** 1명(대본을 읽고 과제를 줌), **기록자** 1명(관찰 기록지를 씀). 둘 다 팀원이어도 되지만, 한 사람이 둘 다 하지는 않아요.

## 1. 준비물

| 준비물 | 내용 | 확인 |
|---|---|---|
| 평가 화면 | 누를 수 있는 화면(`design/prototype.html`). 공유 링크의 "누를 수 있는 화면" 탭에서 "새 탭에서 열기"로 열어요. | ☐ |
| 기기 | 휴대폰 1대 (참가자가 평소 쓰는 방식과 같게). 휴대폰이 어려우면 노트북 브라우저. 충전해 두기 | ☐ |
| 관찰 기록지 | `ut/notes/P1.md`, `P2.md`, `P3.md` (기록자가 노트북으로 쓰거나 인쇄해서 손으로 써요) | ☐ |
| 과제 카드 | 과제 문장 3개를 한 장씩 인쇄한 카드. 진행자가 읽어 준 뒤 참가자 앞에 놓아 다시 볼 수 있게 해요 | ☐ |
| 타이머 | 휴대폰 스톱워치. 과제마다 시간을 재요 | ☐ |
| 보호자 동의 | 만 19세 미만 참가자만. 평가 전에 보호자에게 서면이나 메시지로 동의를 받아 두기 | ☐ |
| 장소 | 조용하고 다른 사람이 화면을 볼 수 없는 곳. 주제가 민감해서 주변에 사람이 있으면 참가자가 솔직하게 말하기 어려워요 | ☐ |

### 평가 전에 확인할 것

- [ ] **화면 시작 위치 맞추기.** 평가 화면은 "온보딩·본인인증"에서 시작해요. 참가자에게 주기 전에 진행자가 약관에 체크하고 "휴대폰으로 본인인증하기"를 눌러 **홈 화면**에 맞춰 두세요.
- [ ] **참가자가 바뀔 때마다 새로고침.** 새로고침하면 알림 동의 배너가 처음처럼 다시 떠요. 그다음 위 방법으로 홈에 맞춰 두세요.
- [ ] **누르면 안 되는 버튼 안내.** 화면 아래 "입력 빠짐 보기", "결과 없음 보기" 같은 회색 버튼과 오른쪽 위 "화면 목록" 버튼은 평가용이 아니에요. 휴대폰에서는 "화면 목록"이 보이지 않아요. 회색 버튼은 참가자에게 "아래 회색 버튼은 만든 사람이 쓰는 거라 누르지 않으셔도 돼요"라고 미리 말해 주세요.
- [ ] **아직 고치지 않은 문제 알아 두기.** 클로드 UT에서 나온 문제 중 아래 두 개가 남아 있으면, 참가자가 이 자리에서 멈출 수 있어요. 도와주지 말고 그대로 기록하세요 (`ut/findings.md`의 F1, F3).
  - 과제 1: 질문을 올린 뒤 내 글이 아니라 다른 사람 글(3시간 전, 댓글 3개)이 보여요.
  - 과제 2: 참가자가 언니 AI에게 직접 질문을 입력하면 돌아오는 답에 밑줄 친 용어가 없어요. 이미 있는 대화 속 밑줄 용어(PMS)를 찾아야 과제를 끝낼 수 있어요.

## 3. 진행할 때 지킬 것

### 진행자
1. **도와주지 않아요.** 버튼, 메뉴, 화면 이름을 말하지 않아요. "커뮤니티를 눌러 보세요" 같은 말은 답을 알려주는 거예요.
2. **막히면 질문으로만 돌려줘요.** "어떻게 하실 것 같아요?", "지금 무엇을 찾고 계세요?"만 써요.
3. **3분 넘게 막히면 다음 과제로 가요.** "괜찮아요, 다음 상황으로 넘어갈게요." 실패로 기록하고, 참가자가 잘못한 게 아니라는 느낌이 들게 말해요.
4. **표정과 말로 정답을 알려주지 않아요.** "맞아요!", "아니요 거기 말고" 같은 반응을 하지 않아요. 고개를 끄덕이는 것도 조심해요. 대신 "네, 계속 말씀해 주세요"라고 해요.
5. **참가자가 "다 했어요"라고 하면 그대로 끝내요.** 성공 기준에 못 미쳐도 고쳐 주지 않아요. 기록은 그대로 남겨요.
6. **말이 없어지면 부드럽게 이끌어요.** "지금 무슨 생각 하고 계세요?"
7. **개인 경험을 묻지 않아요.** 주제가 민감해요. 과제는 가상 상황이라고 거듭 알려 주고, 참가자가 자기 이야기를 꺼내도 더 캐묻지 않아요.
8. **불편해 보이면 바로 멈춰요.** "잠깐 쉬어 갈까요? 그만하셔도 괜찮아요." 그만두면 그때까지의 기록만 남겨요.

### 기록자
1. **참가자가 한 말은 그대로 적어요.** 내 말로 바꾸지 않아요. "이게 뭐지?"라고 했으면 "이게 뭐지?"라고 적어요.
2. **본 것과 해석을 나눠 적어요.** "커뮤니티 카드에서 3초 멈춤"은 본 것, "헷갈린 것 같음"은 해석이에요. 해석은 "그 밖에 본 것" 칸에 적어요.
3. **막힌 곳은 화면과 요소까지 적어요.** 예: "3.0 커뮤니티, 오른쪽 아래 + 버튼을 못 찾음"
4. **시간은 과제 문장을 다 읽은 순간부터 "다 했어요"까지 재요.**
5. **결과는 이렇게 나눠요.**
   - **성공:** 도움 없이 성공 기준 화면에 도착
   - **도움받아 성공:** 진행자가 "어떻게 하실 것 같아요?" 외의 말을 했거나, 참가자가 물어봐서 답을 들은 뒤 성공
   - **실패:** 3분 넘게 막혔거나, 성공 기준에 못 미친 채 "다 했어요"라고 함
6. **이름, 학교, 연락처는 적지 않아요.** P1, P2, P3 번호와 나이대(10대 / 20대)만 적어요.

### 과제별 성공 기준 (기록자용, 참가자에게 말하지 않기)
| 과제 | 성공 기준 | 예상 단계 |
|---|---|---|
| 1. 또래에게 익명으로 묻기 | 질문을 올려 3.2 커뮤니티 게시글 화면에 도착 | 5 |
| 2. 언니 AI에게 묻고 모르는 말 확인하기 | 4.1 언니 AI 채팅에서 5.1 용어 설명 창을 열어 보고 대화로 돌아옴 | 4 |
| 3. 믿을 만한 글 찾아 읽기 | "생리 주기, 왜 매달 조금씩 다를까?" 아티클(2.1)에 도착 | 3~4 |

## 4. 그대로 읽을 대본

> `( )` 안은 진행자가 할 행동이에요. 따옴표 안의 문장은 그대로 읽어요.

### ① 인사
"오늘 와 주셔서 고마워요. 저는 오늘 진행을 맡은 ○○이고, 옆에 있는 ○○은 메모를 해요.

오늘은 저희가 만들고 있는 모바일웹 서비스를 써 보실 거예요. 몸과 성에 대해 궁금한 걸 편하게 물어보고 알아볼 수 있는 서비스예요.

먼저 꼭 말씀드리고 싶은 게 있어요. 오늘 평가하는 건 서비스이지 ○○님이 아니에요. 틀린 답은 없어요. 헤매시는 곳이 있다면 그건 저희가 고쳐야 할 부분이라서, 오히려 큰 도움이 돼요.

그리고 개인적인 경험을 말씀하실 필요는 전혀 없어요. 오늘 드릴 상황은 모두 가상의 상황이에요."

### ② 동의
(만 19세 미만이면 먼저) "시작하기 전에, 보호자분께 받은 동의를 확인할게요." (동의서나 메시지를 확인한다)

"진행하면서 옆에서 메모를 남겨도 될까요? 이름은 적지 않고 번호로만 기록해요. 화면 녹화나 녹음은 하지 않아요.

하다가 불편하시거나 그만두고 싶으시면 언제든 말씀해 주세요. 이유를 말씀하지 않으셔도 괜찮아요."

(참가자가 동의하면 다음으로. 동의하지 않으면 감사 인사를 하고 끝낸다)

### ③ 소리 내어 생각하기
"화면을 쓰시는 동안 떠오르는 생각을 말로 해 주세요. '이건 뭐지?', '여기를 눌러야 하나?', '이건 좋다' 같은 거요. 혼잣말하듯 편하게 하시면 돼요.

제가 중간에 도와드리지 않을 거예요. 실제로 혼자 쓰실 때 어떤지 보고 싶어서예요. 그러니 서운해하지 마세요."

(화면 아래 회색 버튼이 보이면) "아래쪽 회색 버튼들은 만든 사람이 쓰는 거라 누르지 않으셔도 돼요."

### ④ 사전 질문
"시작하기 전에 두 가지만 여쭤볼게요. 답하기 싫으시면 넘어가셔도 돼요."

1. "몸이나 성에 대해 궁금한 게 생기면 보통 어디서 찾아보세요?"
2. "그런 걸 친구나 가족에게 물어본 적이 있나요? 물어보기 어려웠다면 왜였나요?"

### ⑤ 과제 안내
(화면이 홈인지 확인하고 휴대폰을 건넨다)

"이제 상황을 하나씩 읽어 드릴게요. 실제로 그런 상황이라고 생각하고 해 보세요. 다 됐다고 생각하시면 '다 했어요'라고 말씀해 주세요."

### ⑥ 과제 1
(과제 카드 1을 놓고 읽는다. 기록자는 타이머 시작)

"요즘 생리 주기가 갑자기 불규칙해져서 걱정돼요. 내가 누군지 드러나지 않게, 비슷한 경험이 있는 또래들에게 물어보세요."

(끝나면) "이 과제는 얼마나 쉬웠나요? 1(아주 어렵다)부터 5(아주 쉽다)까지 골라 주세요."

(휴대폰을 받아 왼쪽 위 화살표로 하단 메뉴가 있는 화면까지 나간 뒤 "홈"을 눌러 홈 화면으로 돌려 놓는다)

(끝나면) "이 과제는 얼마나 쉬웠나요? 1(아주 어렵다)부터 5(아주 쉽다)까지 골라 주세요."

(홈 화면으로 돌려 놓는다)

(과제 카드 3을 놓고 읽는다. 타이머 시작)

"생리 주기가 왜 매달 다른지, 믿을 만한 글로 차분히 읽어 보고 싶어요. 관련된 글을 찾아 읽어 보세요."

(끝나면) "이 과제는 얼마나 쉬웠나요? 1(아주 어렵다)부터 5(아주 쉽다)까지 골라 주세요."

### ⑨ 사후 질문
"다 끝났어요. 수고 많으셨어요. 마지막으로 세 가지만 여쭤볼게요."

## 5. 끝난 뒤

1. 기록자는 참가자가 간 바로 뒤에 `ut/notes/P번호.md`를 마저 채워요. 기억이 흐려지기 전에요.
2. 진행자와 기록자가 5분 동안 "가장 눈에 띈 것 하나"를 서로 말하고, 기록지의 "그 밖에 본 것"에 적어요.
3. 다음 참가자 전에 평가 화면을 새로고침하고 홈에 맞춰 두어요.
4. 3명이 모두 끝나면 GitHub에 올리고 `/ut-result`를 불러요. 클로드 UT 결과와 비교해 정리해요.
