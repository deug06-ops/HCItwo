## 핵심 기능 (기획서 그대로, v3 기준)
1. 커뮤니티 — 익명 질문(사진 첨부 가능) → 또래 답변 → AI 검수. 전문가 답변 없음. 전문성이 필요한 글은 AI가 지우고 AI Q&A로 옮김(수정 후 직접 등록). 연령대별 탭 분리
2. AI Q&A (기존 '고민상담') — 언니 AI 24시간 상담 + 전문가 질의응답(예약 없음, 채팅형). 연령 제한 없음
3. 성지식 매거진 — "언니가 알려주는 포인트", 전문가 감수, 아티클별 연령 제한
4. 성지식 사전 (기존 '성지식 라이브러리') — 검색·카테고리별 용어사전. 연령 제한 없음
- 공통: 회원가입 시 본인인증, 튜토리얼(구성·사용법·주의사항), 신고(사진 첨부, 승인 시 작성자 이용 정지), 푸시 알림(첫 등록 시 동의 요청)

## 주요 사용 시나리오 (기획서 그대로)
1. 익명 질문 → 답변 받기 [핵심]: 김서윤이 커뮤니티 만 14~18세 탭에 질문하고, AI 검수와 또래 답변을 푸시 알림으로 받아 확인. 전문성이 필요한 질문이면 AI Q&A로 안내
