# 모바일웹 와이어프레임 (가제)

`기획서_v1`(v2, 매거진·고민상담·성지식 확장판)의 4대 핵심 기능(Q&A · 매거진 · 고민상담 · 성지식 라이브러리)을 기반으로 만든 8개 화면 와이어프레임. 홈을 매거진 허브로 두고, 하단 탭(홈/Q&A/상담/지식)으로 4대 기능을 오간다.

- `Main.dc.html` — ① 온보딩 · 연령 선택 (10대/20대)
- `Home.dc.html` — ② 홈 · 매거진 허브 (4대 기능 바로가기, 이번 주 매거진)
- `Article.dc.html` — ③ 매거진 아티클 상세 ("언니가 알려주는 포인트" 코너, Q&A·지식사전 연결)
- `QnA.dc.html` — ④ Q&A · 질문 피드 (커뮤니티 탭, 질문 리스트, 질문하기 버튼)
- `Ask.dc.html` — ⑤ 익명 질문 작성 (카테고리, 본문 입력)
- `Detail.dc.html` — ⑥ 질문 상세 · 답변 타임라인 (또래 답변 → AI 검수 → 전문가 답변, 신고, 관련 매거진 연결)
- `Counsel.dc.html` — ⑦ 고민상담 (언니 AI 즉시 상담, 전문가 1:1 예약 상담)
- `Library.dc.html` — ⑧ 성지식 라이브러리 (검색, 카테고리별 용어사전)

`canvas.json`은 각 화면(artboard)의 캔버스 배치 정보를 담은 인덱스 파일이며, 원본은 Claude Artifact(Design 캔버스)로 작성되었다.
