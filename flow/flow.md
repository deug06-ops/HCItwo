## 플로우 1: 익명 질문 → 답변 받기 [핵심]
퍼소나: 김서윤 (17세, 만 14~18세) / 목표: 들키지 않고 질문해서 또래 답변을 받고, 전문성이 필요한 질문이면 전문가에게 묻기

|---|---|---|---|---|
| 1 | 홈 · 매거진 허브 (2.0) | 앱을 연다 (본인인증·연령 구분은 이미 끝난 상태) | — | |
| 2 | 홈 · 매거진 허브 (2.0) | 하단 탭 '커뮤니티'를 누른다 | 커뮤니티 · 질문 피드 (3.0) | |
| 3 | 커뮤니티 · 질문 피드 (3.0) | 만 14~18세 탭에서 "질문하기"를 누른다 | 익명 질문 작성 (3.1) | 김서윤은 만 14~18세 탭만 보임 (만 19세 이상 탭 접근 불가) |
| 4 | 익명 질문 작성 (3.1) | 카테고리를 고르고 본문을 쓴 뒤 "등록"을 누른다 | 질문 상세 · 답변 (3.2) — 답변 대기 중 | 카테고리·본문 빠짐: 에러 표시, 3.1에 머묾 / 부적절한 글·사진: 업로드 불가 안내, 3.1에 머묾 / 첫 등록: 푸시 알림 동의 (새 화면) 후 3.2 / 전문성 필요(병원·건강): 등록 전에 AI가 "전문가에게 묻는 게 좋아 보여요"라고 알려줌 → "전문가에게 묻기"는 전문가 질문 작성 (4.2, 채팅, 내용 미리 채워짐) → "전문가에게 보내기" → 같은 채팅에 머물며 예상 답변 시간을 보며 기다림, 답변도 이 채팅에 옴 / "고쳐 쓰기"는 3.1에 머묾 |
| 5 | 질문 상세 · 답변 (3.2) | "새 답변" 푸시를 눌러 들어와 또래 답변을 본다. 좋아요를 누르거나 댓글로 더 묻는다 | 끝 (목표 달성) | 댓글로 더 물으면 다시 답변 푸시를 받고 3.2로 돌아옴 / 더 정확한 답이 필요하면 "전문가에게 묻기" → 전문가 질문 작성 (4.2, 채팅, 내용 미리 채워짐) → "전문가에게 보내기" → 같은 채팅에서 전문가 답변을 기다림 |
