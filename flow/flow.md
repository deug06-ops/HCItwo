## 플로우 1: 익명 질문 → 답변 받기 [핵심]
퍼소나: 김서윤 (17세, 만 14~18세) / 목표: 들키지 않고 질문해서 또래 답변을 받고, 전문성이 필요한 질문이면 전문가에게 묻기


| 단계 | 화면 (ID) | 사용자 행동 | 다음 화면 | 갈림길 |
|---|---|---|---|---|
| 1 | 홈 · 매거진 허브 (2.0) | 앱을 연다 (본인인증·연령 구분은 이미 끝난 상태) | — | |
| 2 | 홈 · 매거진 허브 (2.0) | 하단 탭 '커뮤니티'를 누른다 | 커뮤니티 · 질문 피드 (3.0) | |
| 3 | 커뮤니티 · 질문 피드 (3.0) | 만 14~18세 탭에서 "질문하기"를 누른다 | 익명 질문 작성 (3.1) | 김서윤은 만 14~18세 탭만 보임 (만 19세 이상 탭 접근 불가) |
| 4 | 익명 질문 작성 (3.1) | 카테고리를 고르고 본문을 쓴 뒤 "등록"을 누른다 | 질문 상세 · 답변 (3.2) — 답변 대기 중 | 카테고리·본문 빠짐: 에러 표시, 3.1에 머묾 / 부적절한 글·사진: 업로드 불가 안내, 3.1에 머묾 / 첫 등록: 푸시 알림 동의 (새 화면) 후 3.2 |
| 5 | (앱 밖) 푸시 알림 | 글이 올라간 뒤 AI가 검수한다 | — | 전문성 필요(병원·건강): 게시글 삭제 + "전문가와 상담하세요" 푸시 → 누르면 전문가 질문 작성 (새 화면, 4.0 아래) — 내용이 미리 채워져 있고 수정 후 직접 등록 → AI Q&A (4.0)에서 전문가 답변을 기다림 |
| 6 | 질문 상세 · 답변 (3.2) | "새 답변" 푸시를 눌러 들어와 또래 답변을 본다. 도움됐어요·채택을 누르거나 댓글로 더 묻는다 | 끝 (목표 달성) | 댓글로 더 물으면 다시 답변 푸시를 받고 3.2로 돌아옴 / 더 정확한 답이 필요하면 "전문가에게 묻기" → 전문가 질문 작성 (새 화면, 내용 미리 채워짐) → 등록 → AI Q&A (4.0)에서 전문가 답변을 기다림 |

## 플로우 2: 처음 가입하기
퍼소나: 김서윤 (17세, 만 14~18세) / 목표: 처음 들어와서 본인인증을 하고, 앱 사용법과 주의사항을 알고 홈에 도착하기

| 단계 | 화면 (ID) | 사용자 행동 | 다음 화면 | 갈림길 |
|---|---|---|---|---|
| 1 | 온보딩 · 본인인증 (1.0) | 링크나 검색으로 처음 들어온다. 랜딩 페이지 없이 바로 이 화면이 보인다. 버튼 위에서 "인증은 나이 확인에만 쓰고, 이름·전화번호는 다른 사용자에게 보이지 않는다"는 안내를 본다 | — | |
| 2 | 온보딩 · 본인인증 (1.0) | "휴대폰으로 본인인증하기"를 눌러 인증을 마친다 | 약관 동의 (새 화면) | 만 14세 미만: "가입할 수 없어요" 안내만 보여주고 끝 / 인증 취소·실패: 1.0으로 돌아와 다시 시도 |
| 3 | 약관 동의 (새 화면) | "닉네임 없이 모두 익명으로 표시돼요" 안내를 보고 약관에 동의한다 | 튜토리얼 (새 화면) | |
| 4 | 튜토리얼 (새 화면) | 3장(① 앱 구성: 커뮤니티·AI Q&A·매거진·사전 ② 사용법 ③ 주의사항·신고)을 옆으로 넘겨 보고 마지막 장에서 "시작하기"를 누른다 | 홈 · 매거진 허브 (2.0) — 끝 (목표 달성) | 건너뛰기: 주의사항 장으로 바로 가서, 주의사항은 꼭 보고 시작 |

## 플로우 3: 언니 AI에게 묻고 사전으로 더 알아보기
퍼소나: 김서윤 (17세, 만 14~18세) / 목표: 궁금한 걸 언니 AI에게 바로 묻고, 모르는 용어는 사전에서 쉬운 설명으로 확인하기

| 2 | AI Q&A (4.0) | "언니 AI한테 먼저 물어보기" 카드를 누른다 | 언니 AI 채팅 (새 화면) | |
| 3 | 언니 AI 채팅 (새 화면) | 궁금한 걸 묻고 답을 읽는다. 답 속 모르는 용어(밑줄)를 누른다 | 용어 설명 창 (새 화면) | |
| 4 | 용어 설명 창 (새 화면) | 사전의 쉬운 설명을 읽고 창을 닫는다 | 언니 AI 채팅 (새 화면) | |
| 5 | 언니 AI 채팅 (새 화면) | 대화를 이어가고 궁금증이 풀린다 | 끝 (목표 달성) | 병원·건강처럼 전문가 확인이 필요한 질문: 언니 AI가 "전문가에게 물어볼래?"를 제안 → 누르면 전문가 질문 작성 (새 화면, 대화 내용 미리 채워짐) → 등록 → AI Q&A (4.0)에서 전문가 답변을 기다림 |
