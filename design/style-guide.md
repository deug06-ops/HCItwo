# 스타일 가이드

플랫폼: 모바일웹 (기획서 "모바일웹, 설치 없이 바로 접근"), 화면 폭 390px 기준

## 느낌 세 단어
**다정하다 · 믿음직하다 · 편안하다**
- 다정하다: 기획서 톤앤매너 "친한 언니가 동생에게 알려주듯"
- 믿음직하다: 김서윤의 목표 "전문가의 정확한 답변", P2 "절대 비밀 유출이 안된다는 보장"
- 편안하다: 퍼소나의 어려움 "친구·가족에게 민망함", 화면이 눈에 튀지 않게
- 결정 과정: 11-25 A + 인디고 → 갈색 → C(인디고 + 라벤더) → 와이어프레임 베이지·갈색 / 11-27 팀이 앱 전체 색을 #E09DC3 → #B07EAA 그라데이션으로 정함

## 색 (분홍 → 모브 그라데이션)
| 이름 | 코드 | 쓰는 곳 |
|---|---|---|
| 그라데이션 | #E09DC3 → #B07EAA (135도) | 주요 버튼, 선택된 칩, "+" 버튼, 로고 |
| 그라데이션 위 글자 (자두) | #2A1627 | 그라데이션 버튼·칩 글자. 흰 글자는 대비가 2.2~3.3:1이라 읽기 어려워 쓰지 않음 |
| 주 색 (진자주) | #7E4475 | 링크, 선택된 탭, 강조 글자, 내 말풍선 (#B07EAA를 진하게, 흰 글자 대비 7.1) |
| 주 색 연하게 (연분홍) | #F8E8F1 | 안내 상자, 매거진 카드 같은 강조 면 |
| 배경 그라데이션 | #FCEEF6 → #F6F0F6 (위→아래) | 화면 바탕. 단색이 필요할 때는 #FBF6F9 |
| AI·전문가 표시 (블루) | #3F6587 / 배경 #E9F0F6 | AI 검수·전문가 감수 배지 (뜻이 있는 색이라 유지) |
| 또래 표시 (그린) | #3F7347 / 배경 #E9F3EA | 또래 답변·채택 배지 (뜻이 있는 색이라 유지) |
| 면 | #FFFFFF | 카드, 입력칸, 상단 바, 하단 메뉴 |
| 글자 | #2E2430 | 제목, 본문 |
| 보조 글자 | #6E5F6B | 설명, 시간, 메타 정보 |
| 흐린 글자 | #958592 | 입력칸 예시 글, 비활성만 (대비 3.5:1이라 중요한 글에는 쓰지 않음) |
| 선 | #EEDFE8 | 카드 테두리, 구분선 |
| 오류 | #B3261E | 에러 문구 |

대비 (글자/배경): 자두/분홍 끝 7.6 이상, 자두/모브 끝 5 이상, 진자주/흰 7.1, 진자주/연분홍 6.0, 본문/배경 13.9, 보조/배경 5.6, 오류/흰 6.5

## 글자
기본 글꼴: system-ui, Apple SD Gothic Neo, Malgun Gothic (따로 불러오지 않음). 둥글고 부드러운 느낌은 굵기 차이와 둥근 모서리로 줌.

| 단계 | 크기 / 굵기 | 쓰는 곳 |
|---|---|---|
| 큰 제목 | 22px / 800 | 화면 첫 문장 (예: 홈 인사, 온보딩) |
| 제목 | 17px / 700 | 상단 바 제목, 카드 제목 |
| 본문 | 15px / 400, 줄 간격 1.6 | 질문·답변·설명 |
| 보조 | 13px / 400 | 시간, 메타, 안내 |
| 작은 표시 | 12px / 700 | 배지, 칩 |

## 모양
- 모서리: 카드·입력칸 16px, 버튼·칩·배지 끝까지 둥글게(999px), 말풍선 18px (보낸 쪽 모서리 하나만 6px)
- 버튼: 높이 48px, 끝까지 둥근 알약 모양. 주 버튼은 그라데이션 바탕 자두색 글자, 보조 버튼은 흰 바탕 선 테두리
- 누를 수 있는 것은 높이 44px 이상

## 기본 부품
상단 바(뒤로 가기 + 제목), 하단 메뉴(홈/커뮤니티/AI Q&A/사전), 주 버튼, 보조 버튼, 입력칸, 카드, 칩(카테고리·탭), 배지(익명·AI 검수완료·채택), 안내 상자(자물쇠 아이콘), 말풍선(채팅), 확인 창
