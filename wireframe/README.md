# 모바일웹 와이어프레임 (가제)

`기획서_v1`(v3, 2026-11-20)의 4대 핵심 기능(커뮤니티 · AI Q&A · 매거진 · 성지식 사전)을 기반으로 만든 화면 와이어프레임. 홈을 매거진 허브로 두고, 하단 탭(홈/커뮤니티/AI Q&A/사전)으로 4대 기능을 오간다.

- `Main.dc.html` — ① 온보딩 · 본인인증 (인증한 나이로 만 14~18세 / 만 19세 이상 구분)
- `Home.dc.html` — ② 홈 · 매거진 허브 (튜토리얼 안내, 4대 기능 바로가기, 이번 주 매거진, 연령 제한 아티클)
- `Article.dc.html` — ③ 매거진 아티클 상세 ("언니가 알려주는 포인트", 연령 표시, 커뮤니티·사전 연결)
- `QnA.dc.html` — ④ 커뮤니티 · 질문 피드 (만 14~18세 / 만 19세 이상 탭, 전문가 글 이동 안내, 질문하기 버튼)
- `Ask.dc.html` — ⑤ 익명 질문 작성 (카테고리, 본문, 사진 첨부, 검열·등록 전 전문가 안내, 버튼은 "익명으로 질문하기" 하나)
- `Detail.dc.html` — ⑥ 질문 상세 · 답변 (AI 검수 → 또래 답변, 채택·도움됐어요·댓글, 신고)
- `Counsel.dc.html` — ⑦ AI Q&A (언니 AI 즉시 상담, 전문가 1:1 채팅 질의응답)
- `4.2-ExpertAsk.dc.html` — ⑨ 전문가 질문 작성 (나만 보는 1:1 안내, 미리 채운 질문, 예상 답변 시간, 어디서 왔는지, 카테고리, 사진, 나갈 때 확인 창)
- `1.3-Under14.dc.html` — ⑩ 가입 불가 안내 (만 14세 미만, "확인"으로 본인인증에 돌아감)
- `3.3-PushBanner.dc.html` — ⑪ 푸시 알림 동의 (질문 작성 위쪽에 작게 뜨는 배너, 뒤 화면을 가리지 않음)
- `3.1-ExpertNotice.dc.html` — ⑤-2 질문 작성에서 등록할 때 뜨는 "전문가에게 묻는 게 좋아 보여요" 창
- `3.2-Waiting.dc.html` — ⑥-2 질문 상세 · 아직 답변이 없을 때
- `4.2-Sent.dc.html` — ⑨-2 전문가 채팅 · 보낸 뒤 (같은 채팅에 머물고 답변도 여기로)
- `1.2-Tutorial-1/2/3.dc.html` — ⑫ 튜토리얼 3장. 실제 화면 위에 설명을 띄우는 코치마크 방식: 1장 홈의 하단 메뉴, 2장 홈의 기능 카드(어디에 물어볼지), 3장 질문 상세의 신고 버튼(검열·신고·익명). 건너뛰기는 3장으로, 시작하기는 홈으로
- `4.1-OnniChat.dc.html` — ⑬ 언니 AI 채팅 (밑줄 용어 → 용어 설명 창, "전문가에게 물어볼래?" → 전문가 채팅)
- `5.1-TermPopup.dc.html` — ⑭ 용어 설명 창 (사전의 쉬운 설명, 닫으면 채팅으로)
- `3.1-Photo.dc.html` — ⑤-3 질문 작성 · 사진 2장을 첨부한 모습
- `3.4-Report.dc.html` — ⑮ 신고하기 (신고할 글, 이유, 사진 첨부, 승인 시 삭제·이용 정지 안내). 질문 상세의 "신고"에서 들어옴
- `Library.dc.html` — ⑧ 성지식 사전 (검색, 카테고리별 용어사전)

색은 디자인 스타일 가이드(`design/style-guide.md`)의 최종 색(#EEBAB7 → #BAA8D6 그라데이션, 진한 라벤더 #5E4E8E)을 따른다 (2026-11-27).

글자는 최소 12px (디자인 점검 기준, 2026-11-27).

`canvas.json`은 각 화면(artboard)의 캔버스 배치 정보를 담은 인덱스 파일이며, 원본은 Claude Artifact(Design 캔버스)로 작성되었다.
