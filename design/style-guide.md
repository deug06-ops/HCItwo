# 스타일 가이드

플랫폼: 모바일웹 (기획서 "모바일웹, 설치 없이 바로 접근"), 화면 폭 390px 기준

## 느낌 세 단어
**차분하다 · 안전하다 · 푸근하다**
- 차분하다: 화면이 눈에 튀지 않게. 퍼소나 "소문이 날까 봐 걱정된다", 가족과 함께 삶
- 안전하다: P2 "절대 비밀 유출이 안된다는 보장", P7·P8 "전문자료가 더 신뢰됨"
- 푸근하다: 기획서 톤앤매너 "친한 언니가 동생에게 알려주듯". 딱딱한 병원 느낌(P2·P3 "어렵고 딱딱함")을 피하려고 보랏빛 라벤더로 부드럽게
- 결정 과정 (2026-11-25): A + 인디고 → 와이어프레임 갈색 → 최종 C(딥 인디고 + 라벤더 강조, 보랏빛으로 푸근하게)

## 글자
기본 글꼴: system-ui, Apple SD Gothic Neo, Malgun Gothic (따로 불러오지 않음). 둥글고 부드러운 느낌은 굵기 차이와 둥근 모서리로 줌.

| 단계 | 크기 / 굵기 | 쓰는 곳 |
|---|---|---|
| 큰 제목 | 22px / 800 | 화면 첫 문장 (예: 홈 인사, 온보딩) |
| 제목 | 17px / 700 | 상단 바 제목, 카드 제목 |
| 본문 | 15px / 400, 줄 간격 1.6 | 질문·답변·설명 |
| 보조 | 13px / 400 | 시간, 메타, 안내 |
| 작은 표시 | 12px / 700 | 배지, 칩 |

## 모양
- 모서리: 카드·입력칸 16px, 버튼·칩·배지 끝까지 둥글게(999px), 말풍선 18px (보낸 쪽 모서리 하나만 6px)
- 버튼: 높이 48px, 끝까지 둥근 알약 모양. 주 버튼은 인디고 바탕 흰 글자, 보조 버튼은 흰 바탕 선 테두리
- 누를 수 있는 것은 높이 44px 이상

## 기본 부품
상단 바(뒤로 가기 + 제목), 하단 메뉴(홈/커뮤니티/AI Q&A/사전), 주 버튼, 보조 버튼, 입력칸, 카드, 칩(카테고리·탭), 배지(익명·AI 검수완료·채택), 안내 상자(자물쇠 아이콘), 말풍선(채팅), 확인 창
